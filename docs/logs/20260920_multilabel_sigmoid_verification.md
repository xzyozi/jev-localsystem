## 1. 実測結果サマリー

ITインシデント文書から、該当するラベル（Security, Network, Database, Frontend, Hardware）を独立判定し、未正規化 Logit マージン $L = \text{logit}(\text{Yes}) - \text{logit}(\text{No})$ の分布と、Sigmoid 確率変換後の最適しきい値を探索しました。

### ① 未正規化 Logit マージン分布 (ベースライン)

| 分類クラス | サンプル数 | マージン平均 | 最小値 | 最大値 | 分布特性 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **正例 (Positive / 該当)** | 8 件 | **+6.95** | +3.36 | +7.86 | 全件が明確にプラス（強固な確信度） |
| **負例 (Negative / 非該当)** | 17 件 | **-3.81** | -6.72 | +0.81 | ほぼ全件がマイナスに集中 |

## 2. 判明した重大知見（空白統合アルゴリズムの確立）

1. **空白バリアント対数和の必要性**:
   - トークナイザーの内部で `'A'` と `' A'`（スペース付き）に確率が分散している場合、単純な辞書参照では低確率側で上書きされてマージンが狂う現象を特定。
   - `P(A_total) = P('A') + P(' A')` として対数和合算を行うアルゴリズムを導入したことで、**10.76ポイントという極めてクリーンな正負分離** が得られた。
2. **高速マルチラベル推論**:
   - 1ラベルあたりの判定所要時間は約 **120ms〜150ms**。
   - 5ラベルの全探索を直列に行っても **1秒未満（約700ms）** で完走し、実務で十分に実用的な速度を実証。

## 3. 設計（基本設計書 JEV-BD-001）へのフィードバック

- **Task Interface (Multi-Label) 実装仕様の確定**:
  - `ResultMapper` において、各独立ラベルに対して $\text{Margin} = \log(P(A) + P(\text{ }A)) - \log(P(B) + P(\text{ }B))$ を算出。
  - デフォルト判定条件として $\text{Sigmoid}(\text{Margin} + 0.5) \ge 0.80$（または生マージン $\text{Margin} \ge 2.0$）を採用することで、**F1=1.0の型安全なマルチラベル抽出パイプライン** を構築する。
