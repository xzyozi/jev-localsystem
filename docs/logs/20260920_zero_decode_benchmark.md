## 2. 判明した定量的知見

1. **大幅な速度向上（5.4倍〜6.7倍高速）**:
   - 1リクエストあたり約 **150ms〜170ms**（0.15秒）で判定が完了。通常生成の1秒超（1044ms）に比べ、**5倍以上のスループット向上** を確認。
2. **デコードループ（文章組み立て）の排除効果**:
   - 通常生成における時間の約 85%（約900ms）は、1文字ずつトークンを出力する「デコード生成ループ（eval_duration）」に消費されている。
   - Zero-Decode方式では、デコードループを1ステップで打ち切る（単一Forward）ため、計算時間が「プロンプトの読み込み時間（prompt_eval）」のみに短縮される。
3. **型安全性とパースエラーの撲滅**:
   - 通常生成では「`Yes, this query is **vulnerable**...`」や「`No, this is **not** valid...`」のように自然言語文章、マークダウン記号（`**`）、不要な装飾が出現し、後段の正規表現パースが壊れるリスクが常に存在する。
   - Zero-Decodeでは `A` や `B` の記号シグナルのみが直接返るため、パースエラーの発生確率が構造的に0%となる。

## 3. 設計（基本設計書 JEV-BD-001）へのフィードバック

- **推論エンジン（Zero-Decode Inference）の優位性確立**:
  「文章生成を行わず1サイクル推論で完結させる」という基本設計方針が、実務的な判定タスクにおいて**80%以上の計算時間削減**と**100%の型安全性**をもたらすことが実証された。
