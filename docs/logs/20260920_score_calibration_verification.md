## 2. 判明した定量的知見

1. **極端値への偏り（Bang-bang control）の非発生**:
   - 懸念されていた「1か5しか選ばず、中間の2, 3, 4が潰れる現象」は発生せず、**中間層の品質に対しては [3] や [2] を中心とした美しい正規分布状の確率** が形成された。
2. **高精度な連続スコアの導出**:
   - 単に「4」と離散値で返すだけでは見えない、「5寄りの4（4.253点）」や「3寄りの2（2.387点）」という**連続的なグラデーション評価が、単一Forwardパス（わずか約500ms）で完全に取得可能** であることを実証。
3. **温度パラメータ $T$ の設定方針**:
   - デフォルト（$T=1.0$）の状態で十分に自然かつ滑らかな確率分布が得られるため、標準設定は $T=1.0$ とし、より平滑化を望む場合のみ $T=1.2 \sim 1.5$ をオプション適用できる設計が最適と確定。

## 3. 設計（基本設計書 JEV-BD-001）へのフィードバック

- **Task Interface (Score) の実装仕様確定**:
  - `ResultMapper` において、ターゲット語彙 `["1", "2", "3", "4", "5"]` の未正規化Logitを抽出し、Softmax変換を経て $\sum (i \times P(i))$ を算出するパイプラインを正式採用。
  - レスポンスDTOに `expected_score` (float) と `distribution` (dict/list) の両方を格納する型安全なスキーマを定義する。
