## 2. 判明した重大知見

1. **スワップ推論による「偽の判定」の確実な防止**:
   - Pair 3（ほぼ互角のコメント表現）では、順方向の単発推論だけだと「C2の勝ち」と断定されてしまうところでしたが、スワップ検証（順序反転）を行ったことで「不一致（INCONCLUSIVE）」として正しく判定不能・互角として検知できました。
2. **高速性の維持（2回推論でも400ms未満）**:
   - Zero-Decode方式では1回のForwardが約180ms〜200msであるため、**スワップ検証で2回推論を行っても合計400ms未満** で完了します。
   - 従来の文章生成型LLM（1回で1秒以上、スワップなら2秒以上）と比較して、スワップ安全回路を常時オンにしても実用的なリアルタイム速度が維持できることが実証されました。

## 3. 設計（基本設計書 JEV-BD-001）へのフィードバック

- **Task Interface (Choice / Pairwise) への標準装備**:
  2つの選択肢を比較するタスクでは、`PromptBuilder` が順方向と逆方向の2つのプロンプトを自動生成し、`ResultMapper` が両者の整合性を照合する「Swap Resolver」を標準パイプラインとして組み込む仕様を確定。
